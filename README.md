## 📌 一、 环境与版本要求

在开始之前，请确保你的电脑具备以下环境：

- **操作系统**：Windows 10 / Windows 11（推荐）
- **浏览器**：Microsoft Edge（默认已安装）
- **Python 版本**：`Python 3.8` 及以上（强烈推荐 `Python 3.10` 或更高版本）

---

## 🛠️ 二、 初次配置步骤（仅需执行一次）

### 步骤 1：安装 Python

1. 如果电脑还没安装 Python，请前往 [Python 官网](https://www.python.org/downloads/) 下载最新版安装包。
2. **⚠️ 极其重要**：在安装界面的第一步，**务必勾选最底部的 `Add Python to PATH`**，然后再点击 Install。
3. 验证安装：按键盘上的 `Win + R` 键，输入 `cmd` 并回车，在弹出的黑框里输入 `python --version`，只要能看到版本号，即代表安装成功。

### 步骤 2：安装核心依赖库

在刚才打开的命令行（黑框）中，复制并运行以下命令安装所需的库：

```bash
pip install playwright keyboard
```

⚙️ 四、 核心功能与快捷键操作
1. 遇到拦截自动暂停（F9 继续）
如果脚本在详情页检测到异常号码（如：【收货人】字段包含电话号码，或【订单留言】里包含非销售号码/多个号码），脚本会自动停下，并在黑框里爆红字：🚨🚨🚨 触发暂停规则！。

如何操作：此时页面会保留在你的眼前。请你人工核对完毕后，按一下键盘上的 F9 键，脚本会自动关闭当前页面并继续处理下一单。

2. 手动暂停与继续
运行期间，无论何时，只要按下键盘上的 F9 键，即可让脚本原地待命（暂停）。再按一次 F9，恢复执行。

3. 断点续传（断电/断网/下班）
如果在运行中途关闭了黑框，或者电脑关机，第二天想接着跑：

再次双击 启动自动化浏览器.bat 启动浏览器。

进入后台查出相同条件的数据。

重新运行 python rpa_cdp.py。

黑框会检测到同目录下的 progress.json 进度文件，提示：📂 发现历史进度：上次处理到了第 X 页，第 X 条。是否从上次中断的地方继续？

输入 y 并回车，脚本会自动跳到断点所在的页码继续干。如果输入 n，则从头开始跑。

❓ 五、 常见问题与报错处理
Q1：黑框提示 ❌ 连接失败: ...

原因：没有用 .bat 启动浏览器，或者浏览器已经被关闭。

解决：请关闭电脑上所有 Edge 窗口，重新双击 启动自动化浏览器.bat 启动，然后再运行脚本。

Q2：为什么脚本在点击，但我手边的物理鼠标没有动？

原因：这是正常现象。脚本使用的是 Playwright 底层协议发送的“幽灵鼠标”指令，它完美模拟了真实的鼠标轨迹，但不会抢占你电脑的控制权。

好处：你可以在脚本运行期间看视频、聊微信、移动真实的鼠标，互不干扰。

Q3：某几条订单报错 Timeout 10000ms exceeded 然后跳过了？

原因：这些订单可能在系统中存在异常，点击后没有正常弹出新页面，或者网络突然卡顿。

解决：脚本内置了容错跳过机制，会自动关闭卡住的页面，防止卡死。如果想处理它们，可以等整个批次跑完后，手动搜索该订单处理。

Q4：跑完了一天的数据，明天查新数据需要手动删文件吗？

解决：不需要。脚本会自动判断数据特征。只要你查询了新日期的数据并按回车接管，脚本发现数据变了，会自动重置进度，从第 1 页第 1 条开始跑。

Q5：如果脚本彻底卡死，按 F9 也没反应怎么办？

解决：直接强行关闭黑框（CMD窗口），然后关闭浏览器。重新从“第一步：启动专属浏览器”开始操作，脚本会自动读取进度文件，断点续传。
